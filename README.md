# YeeSite LED Controller

DMX lighting control for the YeeSite 200W 720LED RGBW Bar — web UI, audio-reactive mode, QLC+ integration, and MIDI support.

## Hardware

- **Fixture:** YeeSite 200W 720-LED RGBW Bar — 168 DMX channels (168-ch mode)
  - 48 RGB color zones: 24 bottom (L→R), 24 top (R→L, counter-clockwise)
  - 24 white zones: middle row (L→R)
- **DMX interface:** [Open Lighting Architecture (OLA)](https://www.openlighting.org/ola/), ArtNet to `10.0.15.109`, Universe 1
- **MIDI:** MPK Mini via RTP-MIDI (iOS + Mac)

## Reference files

| File | Description |
|------|-------------|
| [`YeeSite-200w-720LED-Light-Bar.pdf`](YeeSite-200w-720LED-Light-Bar.pdf) | Fixture manual — channel maps for 4/16/168-ch modes |

## Components

### `web-controller/` — Flask web UI + SocketIO

Real-time browser UI with 26+ RGB effects, 11 white effects, zone control, MIDI input, and a REST API for Home Assistant.

**Run locally:**
```bash
cd web-controller
pip install -r requirements.txt
python server.py
# → http://localhost:5003
```

**Run with Docker (Unraid):**
```bash
cd web-controller
docker compose up -d --build
```

**Key features:**
- RGBW sliders, color picker, color presets (keys `1`–`0`)
- 26 RGB effects: rainbow, fire, plasma, police, meteor, knight rider, and more
- 11 white effects: breathe, chase, twinkle, rain, etc.
- Per-zone selection on the LED bar visualizer (tap-friendly for tablets)
- Speed, dimmer, strobe, and master brightness controls
- MIDI: pads A1–A8 → effects, B1–B8 → colors, K1–K4 → brightness/speed/rgb/white
- Beat-synced effects triggered from MIDI clock or audio
- REST API for Home Assistant (see [REST API](#rest-api) below)

**Configuration** (env vars or `web-controller/config.py`):

| Variable | Default | Description |
|----------|---------|-------------|
| `OLA_HOST` | `10.0.0.10` | OLA server IP |
| `OLA_PORT` | `9090` | OLA HTTP API port |
| `DMX_UNIVERSE` | `1` | DMX universe |
| `WEB_PORT` | `5003` | Web UI port |
| `FPS` | `60` | Animation frame rate |

### `audio-reactive/` — Mac audio → lighting

Captures system audio on Mac, analyzes frequency bands and beats in real time, and drives the fixture either directly via ArtNet or through the web controller.

**Setup:**
```bash
cd audio-reactive
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

To capture whatever is playing (not just the mic), install [BlackHole](https://existential.audio/blackhole/) and route system audio through it:
```bash
brew install blackhole-2ch
# Audio MIDI Setup → create Multi-Output Device (speakers + BlackHole 2ch)
# Set system output to that device
```

**Usage:**
```bash
python main.py --list-devices                                    # see available inputs
python main.py --device "BlackHole 2ch"                         # capture system audio
python main.py --device "BlackHole 2ch" --mapping spectrum      # spectrum analyzer
python main.py --device "BlackHole 2ch" --mapping beat_reactive # hue-shifting beats
python main.py --mode controller --device "BlackHole 2ch"       # via web controller
```

**Mappings:**

| Mapping | Description |
|---------|-------------|
| `freq_color` | bass→red, mid→green, high→blue; beats flash white |
| `spectrum` | 48-zone log-scale spectrum analyzer with rainbow hue |
| `beat_reactive` | Hue-shifting solid color; spikes bright on each beat |

**Modes:**
- `--mode artnet` — ArtNet UDP directly to `10.0.15.109` (lowest latency, full per-zone control)
- `--mode controller` — SocketIO to the web controller (uses its effects engine)

Tune beat sensitivity in `audio-reactive/config.py`: `BEAT_THRESHOLD`, `BEAT_COOLDOWN`, `PEAK_DECAY`.

### `scripts/` — QLC+ project generators

Python scripts that programmatically regenerate the QLC+ files from scratch.

| Script | Output | Description |
|--------|--------|-------------|
| `rebuild_qxf.py` | `YeeSite-720LED-RGBW-Bar-ALL-MODES.qxf` | Fixture definition for all DMX modes (4/16/168-ch) |
| `rebuild_qxw.py` | `MyFirstLighting.qxw` | Full QLC+ project: scenes, chasers, Virtual Console |

```bash
cd scripts
/usr/bin/python3 rebuild_qxf.py   # regenerate fixture definition
/usr/bin/python3 rebuild_qxw.py   # regenerate QLC+ project
```

> Use `/usr/bin/python3` to avoid the Xcode license prompt on Mac.

## REST API

All endpoints are scoped by lamp ID. The built-in fixture is `yeesite-bar`.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/lamps` | List all lamps |
| `GET` | `/api/lamps/<id>` | Full lamp state |
| `POST` | `/api/lamps/<id>/turn_on` | Turn on (`brightness`, `color`, `effect`) |
| `POST` | `/api/lamps/<id>/turn_off` | Blackout |
| `POST` | `/api/lamps/<id>/color` | Set color `{"r","g","b","w"}` |
| `POST` | `/api/lamps/<id>/effect` | Set effect `{"name","colors","speed"}` |
| `POST` | `/api/lamps/<id>/brightness` | Set brightness `{"value": 0–255}` |
| `POST` | `/api/lamps/<id>/stop` | Stop effects, go dark |

```bash
curl http://localhost:5003/api/lamps/yeesite-bar
curl -X POST http://localhost:5003/api/lamps/yeesite-bar/turn_on \
  -H "Content-Type: application/json" \
  -d '{"color": {"r": 255, "g": 0, "b": 100, "w": 0}, "brightness": 200}'
curl -X POST http://localhost:5003/api/lamps/yeesite-bar/effect \
  -H "Content-Type: application/json" \
  -d '{"name": "rainbow_chase", "speed": 1.5}'
```

## Home Assistant

Add to `configuration.yaml` (replace `CONTROLLER_IP`):

```yaml
rest_command:
  yeesite_turn_on:
    url: "http://CONTROLLER_IP:5003/api/lamps/yeesite-bar/turn_on"
    method: POST
    content_type: "application/json"
    payload: '{"brightness": {{ brightness | default(255) }}}'

  yeesite_turn_off:
    url: "http://CONTROLLER_IP:5003/api/lamps/yeesite-bar/turn_off"
    method: POST

  yeesite_color:
    url: "http://CONTROLLER_IP:5003/api/lamps/yeesite-bar/color"
    method: POST
    content_type: "application/json"
    payload: '{"r": {{ r }}, "g": {{ g }}, "b": {{ b }}, "w": {{ w | default(0) }}}'

  yeesite_effect:
    url: "http://CONTROLLER_IP:5003/api/lamps/yeesite-bar/effect"
    method: POST
    content_type: "application/json"
    payload: '{"name": "{{ effect }}"}'

sensor:
  - platform: rest
    name: YeeSite Bar State
    resource: "http://CONTROLLER_IP:5003/api/lamps/yeesite-bar"
    value_template: "{{ value_json.state }}"
    json_attributes: [brightness, color, effect, effect_list, strobe]
    scan_interval: 5
```
